# Security Policy

## Supported Versions

The project is managed as a private desktop application repository. Security fixes are applied to the latest maintained release line on `main`.

## Reporting A Vulnerability

Please report vulnerabilities privately to `shijinpeng06@126.com`.

Include:

- affected version
- impact summary
- reproduction details
- any logs or screenshots that help confirm the issue

Do not open public GitHub issues for security-sensitive findings.
