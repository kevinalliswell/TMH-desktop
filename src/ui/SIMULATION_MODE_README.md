# TMH模拟数据模式功能说明

## 概述

在 `integrated_control_page.py` 中添加了模拟数据模式功能，允许用户在没有实际设备连接的情况下测试和演示系统功能。

## 功能特性

### 1. 模拟数据按钮
- **位置**: 右侧控制面板的"数据操作"部分
- **状态**: 
  - 关闭状态：橙色按钮，显示"模拟数据: 关闭"
  - 开启状态：绿色按钮，显示"模拟数据: 开启"

### 2. 模拟数据类型
- **温度数据**: 9个温度点（T1-T9），包含随机变化和趋势
- **流量数据**: CO、CO2、N2、H2四种气体的流量
- **重量数据**: 当前重量、重量变化、变化率等
- **时间数据**: 自动推进实验时间

### 3. 数据更新频率
- **更新间隔**: 1秒
- **时间推进**: 每次更新推进1秒（转换为分钟）

## 使用方法

### 开启模拟数据模式
1. 点击"模拟数据: 关闭"按钮
2. 按钮变为绿色"模拟数据: 开启"
3. 系统开始生成模拟数据
4. 图表和数据显示开始更新

### 关闭模拟数据模式
1. 点击"模拟数据: 开启"按钮
2. 按钮变为橙色"模拟数据: 关闭"
3. 系统停止生成模拟数据
4. 图表和数据显示停止更新

## 模拟数据算法

### 温度数据
```python
base_temp = 25 + experiment_time * 2  # 基础温度随时间上升
for i in range(1, 10):
    variation = random.uniform(-5, 5)  # 随机变化
    trend = i * 0.5  # 不同温度点的趋势
    temp = base_temp + variation + trend
```

### 流量数据
```python
CO = 0.5 + random.uniform(-0.1, 0.1)
CO2 = 1.0 + random.uniform(-0.2, 0.2)
N2 = 5.0 + random.uniform(-0.5, 0.5)
H2 = 0.0
total_flow = CO + CO2 + N2 + H2
```

### 重量数据
```python
initial_weight = 100.0
weight_loss = experiment_time * 0.1  # 随时间缓慢失重
weight = initial_weight - weight_loss + random.uniform(-0.01, 0.01)
```

## 状态管理

### 模拟模式状态
- `self.simulation_mode`: 布尔值，True表示开启，False表示关闭
- `self.simulation_timer`: QTimer对象，控制数据更新频率

### 按钮状态同步
- 按钮文本和颜色会根据当前状态自动更新
- 系统消息会显示模式切换信息

## 集成功能

### 与绘图组件集成
- 使用 `ExperimentPlotManager` 更新图表
- 支持实时曲线绘制
- 自动滚动和跟随功能

### 与数据清除集成
- 清除数据时自动关闭模拟模式
- 重置所有相关状态

### 与实验控制集成
- 模拟模式独立于实验运行状态
- 可以在实验运行前测试系统功能

## 注意事项

1. **性能考虑**: 模拟数据每秒更新一次，确保系统性能足够
2. **数据真实性**: 模拟数据包含随机变化，模拟真实设备的数据波动
3. **状态同步**: 确保按钮状态与实际模式状态保持一致
4. **错误处理**: 包含异常处理，确保模拟数据生成不会导致程序崩溃

- `toggle_simulation_mode()`: 切换模拟模式
- `update_simulation_data()`: 更新模拟数据

### 关键变量
- `self.simulation_mode`: 模拟模式状态
- `self.simulation_timer`: 数据更新定时器
