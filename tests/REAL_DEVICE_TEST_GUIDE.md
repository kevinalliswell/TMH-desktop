# 真实设备气体流量稳定性测试指南

## 概述

本指南专门针对连接真实MFC（质量流量控制器）设备的气体流量稳定性测试。与模拟测试不同，真实设备测试能够：

- 验证实际的设备通信稳定性
- 测试真实的硬件响应时间
- 检测设备连接和配置问题
- 评估系统在实际工况下的性能

## 测试前准备

### 1. 硬件连接检查

**MFC设备连接:**
- ✅ MFC设备已正确连接并通电
- ✅ RS485通信线缆连接到正确的COM端口
- ✅ 设备地址配置正确（N2=1, CO=2, CO2=3, H2=4）
- ✅ 气体供应管路已连接（如需要）

**电源和接地:**
- ✅ MFC设备供电电压正常
- ✅ 通信线路接地良好
- ✅ 无电磁干扰源

### 2. 软件配置检查

**通信配置 (`configs/comm_config.json`):**
```json
{
  "COM_RS485_MFC": {
    "port": "COM1",        // 确认正确的COM端口
    "baudrate": 9600,
    "bytesize": 8,
    "parity": "E",
    "stopbits": 1.0
  },
  "SLAVE_ADDRESS_MFC": {
    "N2": 1,
    "CO": 2,
    "CO2": 3,
    "H2": 4
  }
}
```

**测试配置 (`tests/real_device_test_config.json`):**
- 调整测试参数以适应您的设备特性
- 设置合适的流量范围和响应超时

### 3. 安全注意事项

⚠️ **重要安全提醒:**
- 确保气体供应系统安全
- 测试前检查所有管路连接
- 准备紧急停止程序
- 确保测试环境通风良好

## 可用测试类型

### 1. 设备检查 (device_check)
**用途:** 快速验证设备连接和基本功能  
**时间:** 30秒  
**检查内容:**
- 设备连接状态
- 各通道通信质量
- 基本读写操作

```bash
python run_real_device_test.py --test device_check
```

### 2. 通信稳定性测试 (communication_test)
**用途:** 专项测试设备通信稳定性  
**时间:** 2分钟  
**测试内容:**
- 持续的读写操作
- 通信错误率统计
- 响应时间监控

```bash
python run_real_device_test.py --test communication_test
```

### 3. 流量稳定性测试 (flow_stability_test)
**用途:** 测试流量设置的准确性和稳定性  
**时间:** 5分钟  
**测试内容:**
- 各种流量值的设置和验证
- 流量精度测试
- 设置响应时间测试

```bash
python run_real_device_test.py --test flow_stability_test
```

### 4. 长期稳定性测试 (endurance_test)
**用途:** 验证长时间运行的稳定性  
**时间:** 30分钟  
**测试内容:**
- 重复流量切换操作
- 长期通信稳定性
- 系统性能衰减监控

```bash
python run_real_device_test.py --test endurance_test
```

### 5. 压力测试 (stress_test)
**用途:** 高频切换条件下的稳定性  
**时间:** 10分钟  
**测试内容:**
- 快速频繁的流量切换
- 极限响应时间测试
- 错误恢复能力测试

```bash
python run_real_device_test.py --test stress_test
```

## 使用步骤

### 步骤 1: 环境准备
```bash

cd tests

# 检查可用测试
python run_real_device_test.py --list-tests
```

### 步骤 2: 设备连接验证
```bash
# 首先运行设备检查

```

```
  CO2通道: 正常 (当前值: 0.0, 响应时间: 0.134s)
```

根据需要选择合适的测试类型：


## 故障排除

### 常见问题及解决方案

#### 1. 设备连接失败
**症状:** `❌ 设备连接失败`

**可能原因:**
- COM端口配置错误
- MFC设备未通电
- 通信线缆连接问题
- 设备地址配置错误

**解决步骤:**
1. 检查设备管理器中的COM端口
2. 确认MFC设备电源指示灯
3. 检查RS485线缆连接
4. 验证设备地址配置

#### 2. 通信质量差
**症状:** 通信质量 < 95%

**可能原因:**
- 电磁干扰
- 线缆质量问题
- 波特率不匹配
- 设备响应延迟

**解决步骤:**
1. 检查附近是否有干扰源
2. 更换高质量的屏蔽线缆
3. 调整通信参数
4. 增加响应超时时间

#### 3. 流量设置不准确
**症状:** 流量精度 < 95%

**可能原因:**
- 设备校准问题
- 气体供应压力不稳定
- 管路泄漏
- 设备老化

**解决步骤:**
1. 检查设备校准状态
2. 确认气体供应压力稳定
3. 检查管路密封性
4. 联系设备供应商进行维护

#### 4. 响应时间过长
**症状:** 平均响应时间 > 2.0秒

**可能原因:**
- 通信参数不当
- 设备负载过高
- 系统资源不足
- 网络延迟（如果使用网络通信）

**解决步骤:**
1. 优化通信参数设置
2. 减少其他程序的资源占用
3. 检查系统性能
4. 调整测试间隔时间

## 高级配置

### 自定义测试参数

编辑 `real_device_test_config.json` 来调整测试参数：

```json
{
  "test_parameters": {
    "stability_check_interval": 1.0,     // 检查间隔（秒）
    "flow_tolerance": 0.05,              // 流量容差（L/min）
    "response_timeout": 3.0,             // 响应超时（秒）
    "settlement_time": 2.0               // 稳定时间（秒）
  },
  "alert_thresholds": {
    "success_rate_min": 98.0,            // 最小成功率（%）
    "response_time_max": 2.0,            // 最大响应时间（秒）
    "flow_accuracy_min": 95.0,           // 最小流量精度（%）
    "communication_quality_min": 95.0    // 最小通信质量（%）
  }
}
```

### 安全限制设置

```json
{
  "safety_limits": {
    "max_flow_rate": 20.0,               // 最大流量（L/min）
    "emergency_stop_enabled": true,      // 紧急停止功能
    "auto_zero_on_error": true,          // 错误时自动清零
    "max_continuous_errors": 5           // 最大连续错误数
  }
}
```
