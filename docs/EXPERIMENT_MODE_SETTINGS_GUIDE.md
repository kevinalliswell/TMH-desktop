# 实验模式设置功能使用指南

## 功能概述

新增的实验模式设置页面允许用户查看和编辑实验模式配置，包括标准实验模式和自定义实验模式。

## 主要功能

### 1. 标准实验模式（只读）
- **GB/T 13241-2017 铁矿石还原性测定方法**
- **GB/T 13242-2017 铁矿石低温粉化试验方法**  
- **GB/T 13240-2018 球团矿自由膨胀指数测定方法**

标准实验模式为只读模式，用户可以：
- 查看实验流程详情
- 查看各阶段的气体设置
- 查看温度和时间参数
- 了解实验标准要求

### 2. 自定义实验模式（可编辑）
用户可以创建、编辑和管理自定义实验模式：

#### 创建自定义模式
1. 点击"添加自定义模式"按钮
2. 输入模式名称
3. 系统自动创建新的自定义模式

#### 编辑模式信息
- 模式名称
- 描述信息
- 启用/禁用状态

#### 管理实验阶段
- **添加阶段**：点击"添加阶段"按钮，配置阶段参数
- **编辑阶段**：选择阶段后点击"编辑阶段"按钮
- **删除阶段**：选择阶段后点击"删除阶段"按钮

#### 阶段参数配置
每个实验阶段包含以下参数：
- **阶段名称**：HEATING（升温）、STABILIZING（恒温）、REDUCING（还原）、COOLING（冷却）
- **描述**：阶段说明
- **目标温度**：25-1200℃
- **温度容差**：0-50℃
- **持续时间**：0-1440分钟（0表示动态时间）
- **升温速率**：-50到50℃/分钟（负值表示冷却）
- **气体设置**：
  - CO流量：0-15 L/min
  - CO₂流量：0-15 L/min
  - N₂流量：0-15 L/min
  - H₂流量：0-15 L/min

## 使用方法

### 访问实验模式设置
1. 启动TMH系统
2. 在左侧菜单栏点击"⚙️ 实验模式设置"
3. 进入实验模式设置页面

### 查看标准实验模式
1. 在左侧"标准实验模式"列表中选择要查看的模式
2. 右侧显示该模式的详细信息
3. 可以查看各阶段的参数设置

### 管理自定义实验模式
1. 在左侧"自定义实验模式"列表中选择模式
2. 右侧显示可编辑的模式信息
3. 修改基本信息后点击"保存修改"
4. 使用阶段管理功能添加、编辑或删除实验阶段

## 数据存储

- 自定义实验模式数据保存在 `configs/experiment_modes.json` 文件中
- 标准实验模式数据硬编码在程序中，不可修改
- 所有修改会自动保存，无需手动保存

## 界面说明

### 左侧面板
- **标准实验模式列表**：显示所有标准实验模式
- **自定义实验模式列表**：显示所有自定义实验模式
- **添加自定义模式**：创建新的自定义模式
- **删除选中模式**：删除选中的自定义模式

### 右侧面板
- **基本信息**：模式名称、描述、类别、状态
- **实验阶段表格**：显示所有阶段的详细信息
- **阶段操作按钮**：添加、编辑、删除阶段
- **保存修改**：保存当前模式的修改

## 注意事项

1. **标准模式只读**：标准实验模式不可编辑，只能查看
2. **自定义模式编辑**：只有自定义模式可以编辑和删除
3. **数据备份**：建议定期备份 `configs/experiment_modes.json` 文件
4. **参数验证**：系统会自动验证输入参数的有效性
5. **实时保存**：所有修改会立即保存到配置文件

## 技术实现

- 使用PySide6构建用户界面
- 基于JSON文件存储配置数据
- 集成到主窗口的侧边菜单栏
- 支持暗黑主题样式
- 响应式布局设计

## 故障排除

### 常见问题
1. **页面无法加载**：检查依赖模块是否正确安装
2. **数据无法保存**：检查配置文件权限和磁盘空间
3. **界面显示异常**：检查PySide6版本兼容性

### 日志查看
系统会在日志中记录实验模式设置的相关操作，可以通过日志文件排查问题。
