# 实验状态显示功能增强说明

## 概述

本次更新为实验控制系统增强了实验状态显示功能，可以显示详细的阶段信息，包括温度、时间、进度等实时数据。

## 功能特性

### 1. 详细阶段信息显示

现在实验状态面板可以显示：

- **阶段序号**: 当前阶段/总阶段数（例如：阶段2/4）
- **阶段名称**: 升温、恒温、还原、冷却等
- **温度信息**: 当前温度 vs 目标温度（例如：`温度: 855.3°C (目标: 900±5°C)`）
- **时间信息**: 
  - 固定时间阶段：`时间: 15.5/30min`
  - 动态时间阶段：`时间: 3.2min`
- **进度信息**: `进度: 85.6%`

### 2. 实时更新

- 每秒更新一次阶段信息
- 自动计算进度百分比
- 实时显示温度变化

### 3. 支持的实验类型

- GB/T 13241-2017 铁矿石还原性测定方法
- GB/T 13242-2017 铁矿石低温粉化试验方法  
- GB/T 13240-2018 球团矿自由膨胀指数测定方法
- 自定义实验模式

## 技术实现

### 1. 信号机制增强

在 `ExperimentController` 中新增信号：
```python
stage_info_updated = Signal(dict)  # 阶段信息更新，包含详细信息
```

### 2. 阶段信息数据结构

```python
stage_info = {
    "current_stage_index": 2,           # 当前阶段序号（从1开始）
    "total_stages": 4,                  # 总阶段数
    "stage_name": "恒温",               # 阶段名称
    "stage_description": "900℃恒温30min，N₂气氛",
    "current_temp": 898.5,              # 当前温度
    "target_temp": 900.0,               # 目标温度
    "temp_tolerance": 5.0,              # 温度误差范围
    "elapsed_time_seconds": 1850.0,     # 经过时间（秒）
    "elapsed_time_minutes": 30.8,       # 经过时间（分钟）
    "duration_minutes": 30.0,           # 持续时间（分钟）
    "progress_percent": 85.6             # 进度百分比
}
```

### 3. 进度计算逻辑

- **固定时间阶段**：基于经过时间 / 总时间计算
- **升温/冷却阶段**：基于当前温度接近目标温度的程度计算
- **动态阶段**：基于实验控制逻辑判断

## 实验阶段流程示例

### GB/T 13241-2017 铁矿石还原性测定

1. **阶段1/4: 升温** - 升温至900℃，N₂保护
   - 温度: 25.0°C → 900.0°C
   - 时间: 动态（约90分钟，10℃/min）
   - 进度: 基于温度变化

2. **阶段2/4: 恒温** - 900℃恒温30min，N₂气氛  
   - 温度: 900±5°C
   - 时间: 30分钟固定
   - 进度: 基于时间

3. **阶段3/4: 还原** - 还原180min，30%CO+70%N₂
   - 温度: 900±5°C
   - 时间: 180分钟固定
   - 进度: 基于时间

4. **阶段4/4: 冷却** - N₂保护冷却至室温
   - 温度: 900°C → 25°C
   - 时间: 动态（约90分钟）
   - 进度: 基于温度变化

## 注意事项

1. **温度获取**: 依赖T8温度传感器数据，如果传感器不可用会显示0.0°C
2. **时间精度**: 阶段时间以秒为单位更新，显示精度为0.1分钟
3. **进度计算**: 升温/冷却阶段假设起始温度为25°C
4. **错误处理**: 所有方法都包含异常处理，确保系统稳定性

## 性能影响

- 每秒发送一次阶段信息更新信号
- UI更新频率为1Hz，对系统性能影响很小
- 阶段信息计算复杂度为O(1)

## 扩展性

该实现设计具有良好的扩展性：

1. **新增显示字段**: 在`stage_info`字典中添加新字段即可
2. **自定义进度计算**: 重写`_calculate_stage_progress`方法
3. **多种显示格式**: 修改`update_stage_info`方法中的格式化逻辑
4. **国际化支持**: 所有显示文本都可以轻松替换为多语言版本

## 总结

本次增强为实验控制系统提供了更丰富、更直观的状态显示功能，用户可以实时了解实验的详细进展情况，包括温度变化、时间进度、阶段状态等关键信息，大大提升了系统的可用性和用户体验。
