# 现场调试与装机说明

面向每台新机器的安装与通讯调试。核心结论：**通讯协议本身没问题，绝大多数"没数据"是 COM 口/参数配错**——每台机器都要按本机实际串口重新配置并自检。

## 1. 安装

1. 下载最新发布包：<https://github.com/kevinalliswell/TMH-desktop/releases>（当前 `v1.3.260625`）。
2. 解压 `TMH_<版本>_windows_amd64_*.zip`。
3. 运行 `TMH\TMH.exe`（或先执行 `install.bat` 创建快捷方式）。

## 2. 确认本机串口

每台机器的 COM 口分配都不同，不能照搬出厂默认（COM12/COM10/COM15 是开发机的值）。

- 打开「设备管理器 → 端口(COM 和 LPT)」，记下三个 USB-串口适配器各自的 COM 号。
- 注意区分**虚拟串口**（如 ELTIMA、loopback）与真实物理口（如 CH343/CH340/FT232 等 USB-Enhanced-SERIAL）。设备只在物理口上。

## 3. 通信设置（关键一步）

进入应用「通信设置」，逐设备选本机实际 COM 口，参数参考下表，点「保存设置」。

| 设备 | 波特率 | 数据位 | 校验 | 停止位 | 其他 |
|---|---|---|---|---|---|
| 气体流量计 (MFC) | 9600 | 8 | 偶校验 (E) | 1 | 四台共一条总线，从机地址 H2=1 / N2=2 / CO2=3 / CO=4 |
| 温度控制器 | 9600 | 8 | 无校验 (N) | 1 | 从机地址 **0**（已现场验证），9 通道 |
| 电子天平 | 1200 | 8 | 无校验 (N) | 1 | 波特率硬件固定 1200，不可改 |

- **MFC 流量缩放**：N2 = 100%，H2 / CO2 / CO = 10%。
- COM 口随机器变化，按第 2 步实际填写；其余参数一般不动。

## 4. 自检（保存后必做）

**应用内**：点「通信设置」页的「**测试连接**」，逐设备核对：

| 结果 | 含义 | 处理 |
|---|---|---|
| ✓ 通讯正常 | 端口打开且有最新数据 | 正常 |
| ✗ 未连接 | 端口打不开/不存在 | 查 COM 号、接线、适配器 |
| ⚠ 端口已打开但无最新数据 | 口对了但收不到有效帧 | 查从机地址、校验位、接线、设备是否上电 |

**命令行**（不依赖界面，源码环境）：

```bash
python scripts/comm_selftest.py --device all                 # 按 comm_config 测全部
python scripts/comm_selftest.py --device mfc  --port COM3     # 单测 MFC
python scripts/comm_selftest.py --device temp --port COM3 --scan   # 温控地址不明时扫描 0..16
python scripts/comm_selftest.py --device balance --port COM3 --baud 1200
```

## 5. 常见问题排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 某设备红色 / 无数据，但端口存在 | COM 口配错（配到了别的设备或虚拟口） | 用第 2 步核对实际 COM 号 |
| 端口能开但一直无数据 | 从机地址 / 校验位 / 接线不对 | 温控用 `--scan` 找地址；核对校验位 |
| 温度 T1–T9 全空 | 温控站号不对 | 默认 0；扫描找到实际地址后填入 |
| 天平有口但无重量 | 校验位不符 | 默认无校验 (N)；若仍无数据试偶校验 (E) |
| 串口时通时断 / "设备无法使用" | USB 适配器/线缆/供电问题（非软件） | 重插 USB 适配器，换线或换 USB 口 |
| 某路气体流量显示差约 10 倍 | 流量缩放与设备量程不符 | 核对 FLOW_SCALING（N2=100%、其余 10%），逐路对照 MFC 面板实测值 |
| 部分温度通道恒为 0 | 该通道未接热电偶 | 正常，接上即有数据 |

## 6. 可燃气体安全上限（H2 / CO）

- H2、CO 流量默认上限 **5 L/min**，任何路径（手动/实验/程序）超过都会被强制钳制并记日志，作为安全保护。
- 修改上限：「通信设置 → 可燃气体安全上限 → 解锁修改（管理员）」→ 输入管理员密码（默认 `1952`）→ 改值 → 保存。

## 7. 通气前安全核对

- 通入可燃气体前，逐路把气体设到一个已知流量，**对照 MFC 自带面板**确认实际流量一致（尤其 CO / H2）。
- 实验过程结束请用「停止实验」收尾；停止后确认 CO / CO2 / H2 已归零并切到 N2 保护气氛。
