## 脚本功能梳理

### 1. `integrated_control_page.py` - 主控制页面

这是系统的**核心业务逻辑层**，负责：

#### 主要功能模块：

**A. 实验控制管理**
- **实验模式选择**：支持3种GB国标实验模式
  - GB/T 13241-2017 铁矿石还原性测定方法
  - GB/T 13242-2017 铁矿石低温粉化试验方法  
  - GB/T 13240-2018 球团矿自由膨胀指数测定方法
  - 自定义实验
- **实验参数设置**：样品信息、操作员、实验类型等
- **实验流程控制**：开始/停止实验、阶段自动切换

**B. 设备控制**
- **气体流量控制**：N₂、CO、CO₂、H₂四种气体的流量设定
- **天平控制**：清零、设置初始重量
- **温度控制**：9个测温点的实时监控

**C. 数据采集与处理**
- **实时数据采集**：温度、重量、流量数据
- **数据存储**：SQLite数据库存储实验数据
- **数据导出**：支持CSV、Excel、TXT格式导出

**D. 用户界面管理**
- **实时监控面板**：显示关键参数
- **实验状态显示**：当前模式、用时、状态
- **数据表格**：实时显示采集数据
- **图表显示**：温度、流量、重量曲线

## 核心实验逻辑

### 1. 阶段自动切换机制

系统根据**温度**和**时间**条件自动切换实验阶段：

```python
# 示例：GB/T 13241-2017 铁矿石还原性测定
阶段1: 升温阶段 (25℃ → 900℃, 升温速率15℃/min)
阶段2: 恒温阶段 (900℃, 持续30min)  
阶段3: 还原阶段 (900℃, CO+CO₂气氛, 持续180min)
阶段4: 冷却阶段 (900℃ → 25℃, 自然冷却)
```

### 2. 气体控制逻辑

不同阶段自动设置不同的气体流量：

```python
# 升温阶段：N₂保护
N₂: 5.0 L/min, CO: 0.0, CO₂: 0.0, H₂: 0.0

# 还原阶段：还原气氛
N₂: 2.0 L/min, CO: 3.0 L/min, CO₂: 1.0 L/min, H₂: 0.0
```

### 3. 数据采集策略

- **实时数据**：每秒更新显示标签
- **实验数据**：每2秒更新图表和表格
- **数据库保存**：每5秒保存到数据库
- **重量跟踪**：记录实验开始/结束重量，计算失重

### 4. 安全保护机制

- **实验停止时**：自动切换到N₂保护气氛
- **设备异常**：错误提示和状态更新
- **数据备份**：实时保存防止数据丢失

  ↓
