# TMH系统实时数据显示优化

## 问题描述

原始设计中，实时数据显示存在以下问题：

1. **数据不一致** - 显示的数据可能与实际读取到的数据不一致
2. **无效数据处理** - 当没有数据或数据无效时，仍显示过时的数值
3. **初始值不合理** - 新建显示时使用"0.00"作为初始值，误导用户
4. **缺少统一验证** - 各个数据更新方法缺少统一的数据有效性检查

## 优化方案

### 1. 统一数据有效性检查

**新增方法**: `_is_valid_data(value)`

**功能**: 统一检查数据是否有效
- 检查是否为None
- 检查是否为数值类型(int, float)
- 检查是否为NaN或无穷大

```python
@staticmethod
def _is_valid_data(value):
    """检查数据是否有效"""
    if value is None:
        return False
    if not isinstance(value, (int, float)):
        return False
    if np.isnan(value) or np.isinf(value):
        return False
    return True
```

```python
def update_data_display(self, name, value, precision=2):
    """更新实时数据显示 - 确保数据一致性"""
    if name in self.data_displays:
        if value is None:
            formatted_value = "N/A"
        elif isinstance(value, (int, float)) and not (np.isnan(value) or np.isinf(value)):
            formatted_value = f"{value:.{precision}f}"
        else:
            formatted_value = "N/A"
        
        self.data_displays[name].setText(formatted_value)
```

### 3. 优化温度数据更新逻辑

**改进要点**:
- 使用统一的数据有效性检查
- 无效数据时主动显示N/A
- 有效数据和无效数据都要更新显示状态

```python
def update_temperature_data(self, data):
    for i in range(1, 10):
        key = f"T{i}"
        if key in data:
            value = data[key]
            
            # 使用统一的数据有效性检查
            is_valid = self._is_valid_data(value)
            if is_valid:
                # 更新有效数据
                self.temp_widget.update_data_display(display_name, value, 1)
            else:
                # 无效数据时显示N/A
                self.temp_widget.update_data_display(display_name, None, 1)
```

## 优化效果

### 数据一致性提升
- ✅ **准确反映设备状态** - 显示数据严格对应设备读取状态
- ✅ **避免误导信息** - 无数据时明确显示N/A而非过时数值
- ✅ **统一数据验证** - 所有数据类型使用相同的有效性标准

### 用户体验改善
- ✅ **清晰的状态指示** - 用户可以明确知道哪些数据是有效的
- ✅ **一致的界面表现** - 所有数据显示遵循相同的逻辑
- ✅ **减少用户困惑** - 避免显示无意义的0.00或过时数据

### 系统可靠性增强
- ✅ **异常情况处理** - 优雅处理数据异常和设备断连
- ✅ **状态同步** - 显示状态与实际数据状态完全同步
- ✅ **调试友好** - 更容易识别数据源问题

## 技术实现

### 数据流控制
```
设备数据 → 有效性检查 → 有效数据处理 / 无效数据显示N/A → UI更新
```

### 状态管理
- **数据采集中**: 根据实际数据显示数值或N/A
- **数据采集停止**: 所有显示重置为N/A
- **设备断连**: 自动显示N/A

### 错误处理
- 捕获所有数据处理异常
- 异常情况下默认显示N/A
- 记录详细的错误日志便于调试
