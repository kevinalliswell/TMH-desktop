# 数据保存功能实现总结

## 实现概述

成功实现了TMH系统的数据保存功能，支持将实验数据导出为CSV、Excel和TXT三种格式。该功能基于 `chart_tabs` 中的数据表格，提供了完整的用户界面和程序化接口。

## 实现内容

### 1. 核心模块 (`src/utils/data_saver.py`)

#### DataSaver 类
- **功能**: 主要的数据保存器，支持多种格式导出
- **特性**:
  - 支持CSV、Excel、TXT三种格式
  - 自动文件命名（时间戳格式）
  - 进度信号支持
  - 完整的错误处理
  - 依赖库检查

#### DataExportDialog 类
- **功能**: 提供用户友好的导出对话框
- **特性**:
  - 格式选择下拉框
  - 包含表头选项
  - 进度显示
  - 成功/失败反馈

## 技术特性

### 支持格式

#### CSV格式
- 使用UTF-8-BOM编码，确保中文兼容性
- 逗号分隔，兼容Excel
- 自动包含表头

#### Excel格式
- 使用openpyxl库
- 自动设置表头样式（加粗、背景色、居中对齐）
- 自动调整列宽
- 支持中文文件名

#### TXT格式
- 使用制表符分隔
- UTF-8编码
- 便于程序处理

### 数据内容

导出的数据包含以下字段：
1. **时间**: 国标时间格式 (YYYY-MM-DD HH:MM:SS)
2. **实验时长**: 时分秒格式 (HH:MM:SS)
3. **样品温度**: T8传感器数据 (℃)
4. **N2流量**: N2气体流量PV值 (L/min)
5. **CO流量**: CO气体流量PV值 (L/min)
6. **CO2流量**: CO2气体流量PV值 (L/min)
7. **H2流量**: H2气体流量PV值 (L/min)
8. **重量**: 天平重量数据 (g)
9. **实验状态**: 当前实验状态
10. **系统提示**: 系统提示信息

#### 用户反馈
- 成功/失败消息提示

- 详细错误信息

## 使用方法

### 1. 通过控制面板
1. 运行实验或加载已有数据
2. 点击"保存数据"按钮
3. 选择导出格式
4. 选择保存位置
5. 确认导出

### 2. 程序化调用
```python
# 直接导出
success = chart_tabs.export_data('csv', 'data.csv')

# 显示对话框
success = chart_tabs.show_export_dialog()

# 检查数据
count = chart_tabs.get_table_data_count()
```

## 性能考虑

### 内存使用
- 数据提取时使用列表存储，内存占用合理
- 大文件导出时建议分批处理

### 文件大小
- CSV: 最小，纯文本格式
- TXT: 与CSV相近
- Excel: 较大，包含格式信息

### 处理速度
- CSV: 最快
- TXT: 较快
- Excel: 较慢（需要格式处理）

## 扩展性

### 添加新格式
可以通过继承 `DataSaver` 类轻松添加新格式：

```python
class CustomDataSaver(DataSaver):
    def _save_custom(self, data, file_path):
        # 实现自定义格式
        pass
```

### 批量导出
可以扩展支持批量导出多个实验的数据。

### 数据过滤
可以添加数据过滤功能，只导出特定时间范围或条件的数据。

## 注意事项

1. **依赖库**: Excel导出需要安装openpyxl库
2. **文件权限**: 确保目标路径有写入权限
3. **数据完整性**: 导出的是当前表格中的所有数据
4. **文件覆盖**: 同名文件会被覆盖
5. **中文支持**: 所有格式都支持中文内容
