## 2. 通讯协议层

### 2.1 协议文件: `mfcCMQProtocol.py`

#### 2.1.1 支持的协议
- **Modbus-CPL协议** (用于MFC流量计)
  - 设备地址: 01
  - 接口: RS485
  - 波特率: 19200
  - 数据位: 8, 停止位: 1, 校验位: 偶校验(E)

#### 2.1.2 核心功能

**1. 校验和计算 (`CPLSum`)**
```python
def CPLSum(input_str):
    """计算CPL协议的校验和"""
    # UTF-8编码 → 字节求和 → 取反加1 → 转16进制
    byte_str = input_str.encode('utf-8')
    sum_value = sum(byte_str)
    sum_value = (-(sum_value & 0xFF) & 0xFF)
    return f"{sum_value:02X}"
```

**2. 读命令创建 (`create_read_command`)**
```python
# 命令格式: <STX>0100XRS,1001W,2<ETX>9A\r\n
# STX=0x02, ETX=0x03
# 示例: 读取地址1206的2字节数据
create_read_command(device_add=1, data_add=1206, num_bytes=2)
```

**3. 写命令创建 (`create_write_command`)**
```python
# 命令格式: <STX>0100XWS,1001W,2,65<ETX>FE\r\n
# 示例: 写入地址1401，数据为[12, 60]
create_write_command(device_add=1, data_add=1401, data_list=[12, 60])
```

**4. 响应解析 (`parse_response`)**
```python
# 解析格式: <STX>0100X20,30<ETX>F3\r\n
# 提取数据部分，除以10得到实际值
parse_response(response) → 3.0
```

#### 2.1.3 寄存器地址映射
- **1401~1408**: SP0~SP7 (设定流量值)
- **1206-1207**: SP和PV值 (当前流量和设定流量)

def _data_processing_loop(self):
    """数据处理主循环"""
    while not stop_event.is_set():
        # 1. 从设备管理器获取最新数据
        data = self.device_manager.get_status()
        
        # 2. 实时数据 (用于监控面板)
        if data != last_realtime_data:
            self.all_data_updated.emit(data)

            self.experiment_data_sampled.emit(data)
            self.data_buffer.put(data)
            
            # 4. 如果实验运行中，保存到实验数据库

                self._save_experiment_data_point(data)
        
        time.sleep(data_collection_interval)

## 8. 关键机制说明

### 8.1 智能重连机制

**问题背景**
- MFC设备10秒不用自动关闭连接
- 连续错误后需要自动恢复
- 避免永久停滞

**解决方案**
```python
# 指数退避策略
reconnect_delays = [1, 2, 5, 10, 30]  # 秒

def smart_reconnect(self):
    # 1. 计算当前延迟时间
    delay = reconnect_delays[min(attempt, len(delays)-1)]
    
    # 2. 检查是否到达重连时间
    if current_time - last_reconnect_time < delay:
        return False
    
    # 3. 尝试重连
    close_serial_port()
    if open_serial_port():
        reconnect_attempt = 0  # 重置
        return True
    else:
        reconnect_attempt += 1
        return False
```

**特点**
- 永不放弃，持续尝试
- 指数退避，避免频繁重试
- 成功后立即重置计数器

### 8.2 命令队列机制 (MFC)

**问题背景**
- 多个气体通道共享一个串口
- 设置命令需要优先执行
- 避免命令冲突

**优势**

### 8.5 数据采样机制

**双重时间间隔**
```python
# 1. 数据采集间隔 (0.2秒)
#    - 用于实时监控面板
#    - 快速响应，及时更新

# 2. 采样间隔 (1.0秒)
#    - 用于图表和数据表格
#    - 降低数据密度，提高性能

def _data_processing_loop(self):
    while True:
        data = device_manager.get_status()
        
        # 实时数据 (每次循环)
        if data != last_realtime_data:
            all_data_updated.emit(data)
        
        # 采样数据 (按间隔)
        if time.time() - last_sample_time >= sampling_interval:
            experiment_data_sampled.emit(data)
            data_buffer.put(data)
            last_sample_time = time.time()
        
        time.sleep(data_collection_interval)
```

## 10. 异常处理机制

### 10.1 串口异常
- **串口打开失败**: 记录错误，触发重连
- **读取超时**: 重试3次，失败后标记不健康
- **数据解析错误**: 记录警告，返回None

### 10.2 连接异常
- **连续5次错误**: 标记连接不健康
- **触发重连**: 使用指数退避策略
- **永不放弃**: 持续尝试重连

### 10.3 数据异常
- **队列满**: 丢弃最旧数据
- **数据库写入失败**: 重试3次
- **数据格式错误**: 记录警告，跳过该条数据
