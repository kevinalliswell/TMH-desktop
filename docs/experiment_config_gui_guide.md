# 实验模式配置GUI使用指南

## 概述

实验模式配置页面是一个可视化的实验管理界面，集成在主窗体的侧边栏菜单中。用户可以通过图形界面轻松创建、编辑、管理自定义实验模式，无需手动编辑JSON配置文件。

## 访问方式

1. 启动TMH系统主程序
2. 在左侧导航栏中点击 **⚙️ 实验配置** 按钮
3. 进入实验模式配置页面

## 界面布局

### 📋 左侧：实验管理面板

#### 实验列表
- **表格显示**：显示所有可用的实验模式
  - 🔬 **标准实验**：GB国标实验，只读不可修改
  - ⚙️ **自定义实验**：用户创建的实验，可编辑
- **列信息**：
  - **名称**：实验的显示名称
  - **类型**：标准/自定义标识
  - **阶段数**：实验包含的阶段数量
  - **状态**：只读/可编辑状态

#### 管理操作
- **新建实验**：创建全新的自定义实验
- **复制实验**：从现有实验（包括标准实验）复制并创建新的自定义实验
- **删除实验**：删除自定义实验（标准实验不可删除）
- **刷新列表**：重新加载实验配置
- **导入实验**：从JSON文件导入实验配置
- **导出实验**：将实验配置导出为JSON文件

### 🔧 右侧：实验编辑器

#### 选项卡结构
1. **基本信息**：设置实验名称和描述
2. **阶段配置**：可视化编辑实验阶段
3. **配置预览**：实时查看JSON配置

## 详细操作指南

### 🆕 创建新实验

1. 点击 **新建实验** 按钮
2. 在 **基本信息** 选项卡中：
   - 输入实验名称（必需）
   - 输入实验描述（可选）
3. 切换到 **阶段配置** 选项卡
4. 默认包含3个基础阶段：升温、恒温、冷却
5. 根据需要添加或删除阶段
6. 配置每个阶段的参数
7. 在 **配置预览** 中查看生成的配置
8. 点击 **保存配置** 完成创建

### 📝 编辑阶段参数

每个阶段编辑器包含以下参数组：

#### 基本信息
- **阶段类型**：选择阶段类型
  - `HEATING`：升温阶段
  - `STABILIZING`：恒温阶段
  - `REDUCING`：还原阶段
  - `COOLING`：冷却阶段
- **阶段描述**：简要说明阶段目的

#### 温度参数
- **目标温度**：设置目标温度（25-1200℃）
- **温度误差**：允许的温度偏差范围（0-50℃）
- **升温速率**：温度变化速率（-50到+50℃/min）

#### 时间参数
- **持续时间**：阶段持续时间（0-1440分钟）
- **动态时间**：勾选此项表示时间由其他条件决定

#### 气体参数
- **CO流量**：一氧化碳流量（0-50 L/min）
- **CO₂流量**：二氧化碳流量（0-50 L/min）
- **N₂流量**：氮气流量（0-50 L/min）
- **H₂流量**：氢气流量（0-50 L/min）
- **总流量**：自动计算显示总流量

### 🔄 复制现有实验

1. 在实验列表中选择要复制的实验
2. 点击 **复制实验** 按钮
3. 系统自动创建副本，名称后添加"(副本)"
4. 新创建的实验为自定义类型，可进行编辑

### 🗑️ 删除实验

1. 选择要删除的自定义实验
2. 点击 **删除实验** 按钮
3. 确认删除操作
4. 🚨 **注意**：标准实验不可删除

### 📥 导入实验

1. 点击 **导入实验** 按钮
2. 选择JSON配置文件
3. 系统自动验证文件格式
4. 导入成功后添加到自定义实验列表

### 📤 导出实验

1. 选择要导出的实验
2. 点击 **导出实验** 按钮
3. 选择保存目录
4. 系统生成带时间戳的JSON文件

## 参数验证规则

### 🔒 安全限制
系统会自动验证所有参数，确保设备安全：

- **温度范围**：25-1200℃
- **温度误差**：最大50℃
- **流量范围**：0-50 L/min
- **时间范围**：0-1440分钟（24小时）
- **升温速率**：-50到+50℃/min

### ❗ 常见验证错误
- 实验名称不能为空
- 至少需要包含一个实验阶段
- 参数超出安全范围时会显示错误提示
- 气体流量配比需要合理

## 🎨 界面特性

### 视觉设计
- **暗黑主题**：适合实验室环境
- **颜色编码**：
  - 🔬 标准实验：蓝色图标
  - ⚙️ 自定义实验：齿轮图标
  - 状态颜色：只读（蓝色）、可编辑（绿色）

### 交互特性
- **实时预览**：参数修改时立即更新预览
- **智能提示**：鼠标悬停显示详细信息
- **表单验证**：输入时实时验证参数范围
- **分组布局**：相关参数归类显示

## 💡 使用技巧

### 高效工作流程
1. **从模板开始**：复制类似的现有实验作为起点
2. **逐步调整**：先设置基本参数，再细化具体数值
3. **验证预览**：经常查看配置预览确保正确
4. **及时保存**：完成配置后立即保存

### 最佳实践
- **命名规范**：使用清晰描述性的实验名称
- **文档记录**：在描述字段中记录实验目的和特点
- **备份管理**：定期导出重要的自定义实验配置
- **参数合理性**：确保设置的参数符合实际设备能力

## 🚨 注意事项

### 安全警告
- 所有参数都经过验证，但仍需确保符合实际实验需求
- 高温实验需要特别注意安全防护
- 气体配比要符合实验安全标准

### 操作限制
- **标准实验保护**：GB标准实验不可修改，确保合规性
- **删除确认**：删除操作不可撤销，请谨慎操作
- **文件权限**：确保配置文件目录有写入权限

## 🔧 故障排除

### 常见问题

#### 配置保存失败
- **检查文件权限**：确保配置目录可写
- **验证参数**：检查所有参数是否在有效范围内
- **磁盘空间**：确保有足够的存储空间

#### 导入失败
- **文件格式**：确保是有效的JSON格式
- **参数验证**：检查导入文件中的参数是否符合验证规则
- **文件编码**：确保文件使用UTF-8编码

#### 界面显示异常
- **刷新页面**：点击刷新列表按钮
- **重启应用**：关闭并重新启动主程序
- **检查日志**：查看系统日志了解详细错误信息

### 技术支持
如遇到问题，可以：
1. 查看系统日志文件获取详细错误信息
2. 检查配置文件 `configs/experiment_modes.json`
3. 运行测试脚本 `test_experiment_config.py` 验证功能
4. 参考技术文档或联系支持团队
