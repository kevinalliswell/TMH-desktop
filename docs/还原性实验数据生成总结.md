### 实验数据点（experiment_data表）

每个实验包含181个数据点，采集间隔为1分钟，实验总时长为3小时（180分钟）。

**数据字段包括：**
- `experiment_id`: 实验ID
- `timestamp`: 时间戳
- `experiment_duration`: 实验时长（HH:MM格式）
- `temperature`: 温度（℃）
- `weight`: 重量（g）
- `weight_loss`: 失重百分比（%）
- `co_flow`: CO流量（L/min）
- `co2_flow`: CO2流量（L/min）
- `n2_flow`: N2流量（L/min）
- `h2_flow`: H2流量（L/min）
- `experiment_status`: 实验状态
- `system_message`: 系统消息

## 符合国标的设计参数

### 实验条件
- **目标温度**: 900℃ ± 10℃
- **气体流量**: 15 L/min ± 0.5 L/min
- **气体组成**: CO 30%, CO2 20%, N2 50%
- **实验时长**: 3小时
- **样品重量**: 500g

### 还原度计算
根据国标GB/T 13241-2017公式：
```
Rt = (ΔW / (W0 × O2%)) × 100%
```
其中：
- Rt: t时刻的还原度（%）
- ΔW: 失重量（g）
- W0: 初始重量（g）
- O2%: 氧含量百分比（%）

### 数据特点
1. **温度曲线**: 前30分钟升温至900℃，后续保持恒温
2. **重量变化**: 模拟典型的还原失重过程，初期快速失重，后期趋于平缓
3. **气体流量**: 保持稳定，有轻微随机波动模拟真实情况
4. **还原度**: 根据指数衰减函数模拟，最终还原度在85-95%之间

3. **时间序列**: 严格按照国标要求的时间间隔采集数据
4. **数据完整性**: 确保所有必需字段都有有效数据
