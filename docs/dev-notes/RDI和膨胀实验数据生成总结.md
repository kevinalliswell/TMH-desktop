## 符合国标的设计参数

### 低温粉化指数实验（GB/T 13242-2017）

- **目标温度**: 500℃ ± 10℃
- **气体流量**: 15 L/min ± 0.5 L/min
- **气体组成**: CO 30%, CO2 20%, N2 50%
- **实验时长**: 1小时
- **样品重量**: 500g

**RDI指标计算**：
- RDI+6.3: >6.3mm颗粒重量百分比
- RDI+3.15: >3.15mm颗粒重量百分比  
- RDI-0.5: <0.5mm颗粒重量百分比

### 球团膨胀实验（GB/T 13240-2018）

- **最高温度**: 1000℃
- **气体流量**: 15 L/min ± 0.5 L/min
- **气体组成**: CO 30%, CO2 20%, N2 50%
- **实验时长**: 3小时
- **样品重量**: 500g

**膨胀指数计算**：
```
Vfs = (V1 - V0) / V0 × 100%
```
其中：
- Vfs: 自由膨胀指数
- V0: 初始体积
- V1: 最终体积

## 数据特点

### 低温粉化指数实验
1. **温度曲线**: 前20分钟升温至500℃，后续保持恒温
2. **重量变化**: 模拟轻微的还原失重过程，失重率0.5-2%
3. **实验时长**: 1小时，数据采集间隔1分钟
4. **数据点数**: 每个实验61个数据点

### 球团膨胀实验
1. **温度曲线**: 前60分钟升温至1000℃，中间60分钟恒温，最后60分钟冷却
2. **重量变化**: 模拟轻微的表面氧化，失重率0.1-0.5%
3. **实验时长**: 3小时，数据采集间隔1分钟
4. **数据点数**: 每个实验181个数据点

## 技术实现

数据生成脚本采用了以下技术：

1. **数学模型**: 
   - RDI实验：使用指数衰减函数模拟还原过程
   - 膨胀实验：使用分段函数模拟升温-恒温-冷却过程
2. **随机性**: 添加适当的随机波动模拟真实实验环境
3. **时间序列**: 严格按照国标要求的时间间隔采集数据
4. **数据完整性**: 确保所有必需字段都有有效数据
