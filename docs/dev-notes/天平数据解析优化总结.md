# 天平数据解析优化总结

## 🎯 优化目标

根据提供的天平数据流，优化天平数据解析功能，确保能正确处理：
1. **A00确认信息**：去皮命令响应中包含的确认信息
2. **前导零格式**：重量数据格式如 `+00000.0 G S`
3. **数据精度**：确保所有重量数据保留小数点3位

## 📊 数据流分析

根据提供的实际数据流：

```

A00
+00000.0 G S

[2025-09-08 12:44:02.351]# RECV ASCII>
+00000.0 G S

[2025-09-08 12:44:02.768]# RECV ASCII>

```

### 关键发现：
1. **去皮命令响应**：发送去皮命令后，天平先返回 `A00` 确认，然后返回重量数据
2. **数据格式**：重量数据格式为 `+00000.0 G S`，包含前导零
3. **多行响应**：去皮命令可能返回多行数据

```python
def _parse_data(self, data: str) -> Optional[float]:
    # 处理可能包含A00确认信息的数据
    if '\n' in data:
        # 如果包含换行符，取最后一行作为重量数据
        lines = data.strip().split('\n')
        for line in reversed(lines):
            if self.STABLE_DATA_MARKER in line:
                data = line.strip()
                break
    
    # 验证数据是否为稳定数据
    if self.STABLE_DATA_MARKER not in data:
        return None

    # 匹配数值部分，支持前导零格式
    pattern = re.compile(r'([+-]\d+\.\d+)')
    # ... 确保精度控制
    weight = round(weight, 3)
```

### 2. 去皮命令处理优化 (`send_tare_command`)

**修改前**：
```python
def send_tare_command(self) -> bool:
    # 简单等待和读取
    time.sleep(self.COMMAND_WAIT_TIME)
    # 只检查重量数据
```

**修改后**：
```python
def send_tare_command(self) -> bool:
    # 增加等待时间以接收完整响应
    time.sleep(1.0)
    
    # 检查是否包含A00确认信息
    has_a00_confirmation = 'A00' in response
    if has_a00_confirmation:
        self.logger.debug("收到A00确认信息")
    
    # 处理多行响应
    lines = response.splitlines()
    for line in lines:
        # 检查重量数据
        if self.STABLE_DATA_MARKER in line:
            # 解析重量并检查是否接近0
            if abs(weight) < 0.01:
                return True
            elif has_a00_confirmation:
                # 即使有重量，如果有A00确认，也认为成功
                return True
    
    # 如果没有找到G S数据，但有A00确认，也认为成功
    if has_a00_confirmation:
        return True
```
