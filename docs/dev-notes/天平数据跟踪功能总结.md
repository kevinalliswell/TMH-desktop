## 🚀 使用方法

### 基本使用示例
```python
from src.device_clients.balance_data_tracker import BalanceDataTracker

# 创建跟踪器
tracker = BalanceDataTracker()

# 添加数据回调
def data_callback(data):
    print(f"重量: {data['weight_formatted']}g")

tracker.add_data_callback(data_callback)

# 开始跟踪
tracker.start_tracking()

# 运行一段时间后停止
time.sleep(10)
tracker.stop_tracking()
```

### 运行测试
```bash

```

## 🔍 技术实现细节

### 1. 精度控制
- 在 `_parse_data()` 函数中使用 `round(weight, 3)` 确保精度
- 在所有数据存储位置都进行精度控制
- 统一使用 `f"{weight:.3f}"` 格式化显示

### 2. 线程安全
- 使用 `threading.Lock()` 保护共享数据
- 所有数据操作都是线程安全的
- 支持多线程环境下的数据跟踪

### 3. 错误处理
- 完整的异常处理机制
- 详细的日志记录
- 优雅的错误恢复

### 4. 内存管理
- 历史数据有最大限制（默认1000条）
- 自动清理旧数据
- 避免内存泄漏

## 📈 性能优化

### 1. 数据采集优化
- 采集间隔可配置（默认0.1秒）
