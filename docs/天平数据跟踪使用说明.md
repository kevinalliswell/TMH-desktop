# 天平数据跟踪使用说明

## 概述

本系统提供了完整的天平数据跟踪功能，确保所有重量数据都保留小数点3位精度。系统包含以下组件：

1. **BalanceClient** - 天平设备客户端，负责串口通信和数据采集
2. **BalanceDataTracker** - 数据跟踪器，提供高级数据管理和统计功能
3. **测试脚本** - 用于验证功能的测试工具

## 功能特性

### 1. 数据精度保证
- 所有重量数据自动保留小数点3位
- 数据解析时自动进行精度控制
- 显示和存储时统一格式化为3位小数

### 2. 实时数据跟踪
- 实时采集天平数据
- 支持数据回调函数
- 提供历史数据查询
- 自动统计信息计算

### 3. 数据导出功能
- 支持CSV、TXT、JSON格式导出
- 包含完整的时间戳和格式化数据
- 自动生成统计报告

## 使用方法

### 1. 基本使用

```python
from src.device_clients.balance_data_tracker import BalanceDataTracker
from src.utils.path_manager import PathManager

# 创建跟踪器
config_path = PathManager.get_config_path('comm_config.json')
tracker = BalanceDataTracker(config_path)

# 添加数据回调函数
def data_callback(data):
    print(f"重量: {data['weight_formatted']}g")

tracker.add_data_callback(data_callback)

# 开始跟踪
tracker.start_tracking()

# 运行一段时间后停止
time.sleep(10)
tracker.stop_tracking()
```

### 2. 获取统计信息

```python
# 获取统计信息
stats = tracker.get_statistics()
print(f"总读数: {stats['total_readings']}")
print(f"平均重量: {stats['avg_weight']:.3f}g")
print(f"最小重量: {stats['min_weight']:.3f}g")
print(f"最大重量: {stats['max_weight']:.3f}g")
```

### 3. 导出数据

```python
# 导出为CSV格式
tracker.export_data("weight_data.csv", "csv")

# 导出为JSON格式
tracker.export_data("weight_data.json", "json")
```

## 数据格式

### 原始数据格式
天平输出的原始数据格式：`"+00015.123 G S"`

### 解析后数据格式
```python
{
    'timestamp': 1699123456.789,
    'datetime': '2024-01-01 12:34:56.789',
    'weight': 15.123,  # 保留3位小数
    'weight_formatted': '15.123'  # 格式化字符串
}
```

### 统计信息格式
```python
{
    'total_readings': 1000,
    'valid_readings': 995,
    'invalid_readings': 5,
    'avg_weight': 15.123,
    'min_weight': 10.000,
    'max_weight': 20.000,
    'running_time': 60.5
}
```

## 配置要求

### 1. 串口配置
确保 `comm_config.json` 中包含正确的天平串口配置：

```json
{
    "COM_RS232_Balance": {
        "port": "COM3",
        "baudrate": 9600,
        "bytesize": 8,
        "parity": "N",
        "stopbits": 1,
        "xonxoff": 0
    }
}
```

### 2. 天平设备要求
- 支持RS232通信
- 输出格式包含"G S"稳定标识
- 数据格式为：`+/-数字.数字 G S`

## 注意事项

1. **数据精度**：系统自动确保所有重量数据保留3位小数
2. **线程安全**：所有数据操作都是线程安全的
3. **内存管理**：历史数据有最大限制（默认1000条）
4. **错误处理**：包含完整的错误处理和日志记录
5. **资源清理**：使用完毕后务必调用 `stop_tracking()` 方法

## 故障排除

### 1. 串口连接问题
- 检查串口配置是否正确
- 确认串口未被其他程序占用
- 验证波特率等参数设置

### 2. 数据解析问题
- 检查天平输出格式是否包含"G S"标识
- 验证数据格式是否符合预期
- 查看日志文件获取详细错误信息

### 3. 性能问题
- 调整采集间隔（默认0.1秒）
- 限制历史数据大小
- 检查系统资源使用情况

## 扩展功能

### 1. 自定义数据回调
```python
def custom_callback(data):
    # 自定义数据处理逻辑
    if data['weight'] > 100:
        print("重量超过100g！")
    
tracker.add_data_callback(custom_callback)
```

### 2. 数据过滤
```python
def filtered_callback(data):
    # 只处理特定范围的重量
    if 10 <= data['weight'] <= 50:
        print(f"重量在范围内: {data['weight_formatted']}g")
```

### 3. 实时监控
```python
def monitor_callback(data):
    # 实时监控重量变化
    current_weight = data['weight']
    if hasattr(monitor_callback, 'last_weight'):
        change = current_weight - monitor_callback.last_weight
        if abs(change) > 0.1:
            print(f"重量变化: {change:+.3f}g")
    monitor_callback.last_weight = current_weight
```
